# Redlands One

> Independent software, technology, and experimental projects.

## Projects

### Prut

A programming language built from scratch, focused on simple syntax, experimentation, and learning how programming languages work.

### Moldova OS

An experimental operating system project focused on exploring operating-system design and development.

## About

Redlands One is an independent technology organization building software, experimenting with new ideas, and learning through hands-on projects.

Projects range from programming languages and operating systems to software, networking, and other technology experiments.
